# 작업 노드 수행

[!DNL Adobe Journey Optimizer B2B Edition]의 작업 노드를 사용하여 여정 또는 계정의 사용자에 대한 작업을 정의합니다. 계정 작업과 사용자 작업을 비교하고 각 여정 유형이 지원하는 작업을 알아봅니다.

>[!VIDEO](https://video.tv.adobe.com/v/3443207/?quality=12&learn=on)

## 작업 노드 기본 사항

이 비디오에서는 다음 주제를 다룹니다.

* 작업의 목적은 여정에 있습니다.
* 계정 작업과 사용자 작업의 차이점입니다.
* 여정 유형 전반에 걸친 작업 지원.

## 관련 설명서

구성 단계 및 지원되는 계정 및 사용자 작업에 대해서는 [사용 안내서에서 작업 수행](https://experienceleague.adobe.com/en/docs/journey-optimizer-b2b/user/journeys/journey-nodes/action-nodes){target="_blank"}을 참조하세요.
