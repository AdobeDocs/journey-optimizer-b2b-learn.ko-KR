# 이벤트 노드 수신

이벤트가 발생할 때 여정을 진행하려면 [!DNL Adobe Journey Optimizer B2B Edition]의 [!UICONTROL 이벤트 수신] 노드를 사용하십시오. 여정 및 개인 이벤트를 비교하고, 일치 기준을 정의하고, 시간 초과를 구성하여 계정이 대기하는 시간을 제어합니다.

>[!VIDEO](https://video.tv.adobe.com/v/3443219/?quality=12&learn=on)

## 노드 핵심 사항 수신

이 비디오에서는 다음 주제를 다룹니다.

* 계정 이벤트와 개인 이벤트의 차이입니다.
* 이벤트 트리거와 일치하는 기준.
* 지정된 시간 내에 발생하지 않는 이벤트에 대한 시간 제한 설정입니다.

## 관련 설명서

지원되는 이벤트, 구성 단계 및 시간 제한 옵션에 대해서는 [사용 안내서에서 이벤트 수신](https://experienceleague.adobe.com/ko/docs/journey-optimizer-b2b/user/journeys/journey-nodes/listen-for-event-nodes){target="_blank"}을 참조하세요.
