# 구매 그룹 역할 템플릿

[!DNL Adobe Journey Optimizer B2B Edition]에서 역할 템플릿을 만드는 방법을 알아봅니다. 이러한 템플릿은 구매 결정에 참여하는 사람, 역할에 할당되는 사람, 구매 그룹을 완성하는 이유 등을 정의합니다. 이 비디오에서는 템플릿 만들기, 역할 구성 및 게시에 대해 설명합니다.

이 자습서는 계정 기반 마케팅을 위해 [!DNL Journey Optimizer B2B Edition]을(를) 사용하고 각 계정의 올바른 이해 당사자를 타겟팅하려는 마케터와 관리자를 위한 것입니다.

>[!VIDEO](https://video.tv.adobe.com/v/3433079/?learn=on)

다음을 수행하는 방법을 알아보세요.

* 구매 그룹에서 역할 템플릿 인벤토리를 열고 초안 템플릿을 라이브 템플릿과 구별합니다.
* 고유한 이름과 설명을 사용하여 새 역할 템플릿을 만듭니다.
* 가중치, 자동 할당 및 완전성 요구 사항을 포함하여 역할을 구성합니다.
* 직함 일치 등 각 역할에 대한 할당 조건을 정의합니다.
* 모든 참여자를 포함하려면 의사 결정자, 실무자 및 영향력 행사자와 같은 역할을 더 추가합니다.
* 조건이 일치하는 첫 번째 역할에 할당되도록 역할 우선 순위를 설정합니다.
* 완결성 점수 설정을 사용하여 각 역할에 필요한 멤버 수를 설정합니다.
* 상태가 라이브로 변경되고 솔루션 관심사에 사용할 수 있도록 템플릿을 게시합니다.

자세한 내용은 사용 안내서에서 [그룹 역할 템플릿 구매](https://experienceleague.adobe.com/ko/docs/journey-optimizer-b2b/user/accounts/buying-groups/buying-groups-role-templates)를 참조하십시오.
